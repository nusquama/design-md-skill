# Examples

This folder will hold worked sample outputs (a `design.md` + `design-tokens.json` + `tokens.css` produced from a real source) so agents and humans can see the expected quality bar.

Add one example per source type:
- `website/` — from a live URL via designlang
- `image/` — from a screenshot via k-means + vision
- `codebase/` — from a frontend repo

Each example should include a short `source.md` noting the input and any limitations.
